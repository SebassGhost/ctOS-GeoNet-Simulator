# ctOS-GeoNet-Simulator

Visualizador geográfico interactivo que simula la conectividad y el flujo de datos de dispositivos urbanos sobre un mapa del mundo real, utilizando únicamente datos simulados.

Este proyecto explora cómo miles de dispositivos de una ciudad inteligente (cámaras, vehículos, sensores, teléfonos móviles, etc.) podrían conectarse a un sistema central, mostrando enlaces dinámicos, pulsos de tráfico y estados de red en tiempo real.

>  Este proyecto NO realiza escaneo de redes reales ni recolección de datos reales.  
> Todos los dispositivos, direcciones, eventos y flujos de datos son completamente simulados y se usan únicamente con fines educativos y visuales.

---

## Concepto

Las ciudades modernas dependen de sistemas altamente interconectados. En lugar de representar esta información como tablas o números, este proyecto busca **traducir conceptos de red en una visualización geográfica e intuitiva**, inspirada en paneles de monitoreo utilizados en infraestructuras de ciudades inteligentes.

El objetivo es convertir información abstracta en una experiencia visual clara, inmersiva y comprensible.

---

## Funcionalidades (Planeadas)

-  Visualización sobre mapa real (pan y zoom)
-  Nodo central del sistema (ctOS)
-  Dispositivos urbanos distribuidos geográficamente
-  Conexiones dinámicas entre nodos
-  Pulsos animados que representan tráfico de datos
-  Estados de dispositivos (normal / inestable / comprometido)
-  Tráfico de red completamente simulado
-  Estética visual estilo hacker (opcional)
